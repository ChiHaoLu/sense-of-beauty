# Street Cap

EV(曝光補償)和 ISO 是兩個不同層次的東西,簡單講:

**ISO** 是感光度,直接決定畫面亮度和雜訊。數字越大越亮,但雜訊也越多。
- 白天戶外:100–400
- 室內、陰天:400–1600
- 夜晚、暗光:1600–6400+
- 原則:**先把 ISO 壓到夠用就好**,優先用光圈和快門控制曝光,ISO 是最後手段

**EV(曝光補償)** 是告訴相機「你測光測得不準,幫我加亮或減暗」。單位是「級」(stop),通常 ±3 EV 範圍。
- +EV:畫面變亮(拍雪景、白色物體、逆光人像時用,避免相機把白拍成灰)
- -EV:畫面變暗(拍黑色物體、夜景燈光時用,避免相機把黑拍成灰)
- 口訣:**「白加黑減」**

**實際操作流程**(光圈優先 A/Av 模式為例):
1. 設定光圈(控制景深)
2. ISO 先設 Auto 或手動壓低
3. 拍一張看結果
4. 太暗 → +EV;太亮 → -EV;有雜訊但已經夠亮 → 降 ISO
5. 快門太慢手震 → 拉高 ISO 或開大光圈

如果是全手動 M 模式,EV 通常就沒作用了(因為光圈快門 ISO 全部你自己決定),這時看相機裡的曝光標尺,指針在 0 就是相機認為的標準曝光。

高動態範圍場景的典型問題——窗外或燈光太亮,室內人臉太暗,相機感光元件吃不下這麼大的光差。GRIII 有幾個解法:

**1. 構圖避開光源(最簡單)**
讓人背對窗戶會逆光、面對窗戶會死白。最好的角度是**讓人側身對窗**,窗光當側光打在臉上,背景再帶一點室內環境,光差自然縮小。

**2. 改變測光模式**
GRIII 預設多重測光,在這種場景會被亮處拉走。切到 **「中央重點」或「重點測光」**,對著人臉測光,EV 不用補太多,人臉就會準。背景白掉一點點是正常的,反而有氛圍。

**3. 用 RAW + 後製救回**
這是 GRIII 最強的地方。**拍 RAW,曝光以人臉為準**(背景過曝沒關係),後製在 Lightroom 把 Highlights 拉到 -60 到 -100、Whites 也拉低,窗外細節常常救得回來。JPEG 直出就回不來了。

**4. Highlight-Weighted 測光(保背景)**
如果你想保住背景、人臉用後製拉亮:測光改成 **「亮部加權」**,相機會以最亮處不過曝為準,人臉會變暗,RAW 後製拉 Shadows +60~80、Blacks +30,人臉細節通常也救得回。

**5. 主動補光**
咖啡廳常見的補光是**請對方靠近窗邊但側身**,或**找一面白牆當反光板**(讓人面向白牆那側)。手機開白色螢幕從側邊補也行,亮度夠近距離用。

**GRIII 實戰建議設定:**
- 模式:Av(光圈優先)
- 光圈:F2.8–F4(F2.8 散景強但對焦薄)
- ISO:Auto,上限設 ISO 3200 或 6400(GRIII 高 ISO 還算乾淨)
- 測光:中央重點
- 檔案:RAW + JPEG
- 對焦:Snap 或 AF 點選臉

最關鍵還是**第一點**——人的位置動一下,比什麼設定都有效。
